# Marketing & Content Strategy: Tricks 66-75

Content is how you attract, engage, and convert.

## 10 Marketing & Content Strategy Techniques

### 66. SEO Blog Outlines
**Create blog posts** that rank in search and drive traffic.

**SEO blog structure:**
1. Title (keyword-rich, compelling)
2. Meta description (155 characters max)
3. Introduction (hook + overview)
4. Section 1: [Main benefit]
   - Subheadings (use keywords)
   - Content (answer the question)
   - Example (make it concrete)
5. Section 2: [Secondary benefit]
6. Section 3: [More depth]
7. FAQ section (common follow-up questions)
8. Conclusion (summary + call to action)

**Example:**
```
Create an SEO blog outline for [topic].

Target keyword: [What people search for]
Search intent: [Why are they searching]
Target audience: [Who reads this]
Goal: [What action do you want]

Outline should:
- Naturally include the keyword
- Answer the main question completely
- Include real examples
- Address common follow-ups
- End with clear call-to-action

Make it scannable (headers, bullets, short paragraphs).
```

### 67. Ad Copy Variations
**Create multiple versions** of promotional copy to test.

**Ad copy formula:**
1. Hook: Grab attention (curiosity, benefit, problem)
2. Body: Why it matters (proof, social proof, specifics)
3. Call-to-action: What should they do (clear and urgent)

**Variation approaches:**
- Benefit-focused: "Save 10 hours per week"
- Problem-focused: "Tired of scheduling nightmares?"
- Social proof: "Join 5,000+ users who..."
- FOMO: "Limited spots available"
- Curiosity: "The one thing nobody tells you..."

**Example:**
```
Create 5 different ad copy variations for [product/service].

What you're promoting: [Offering]
Target audience: [Who you're reaching]
Main benefit: [Why they should care]
Unique angle: [What makes you different]
CTA: [What should they do]

Each variation should use a different angle:
1. Benefit-focused
2. Problem-focused
3. Social proof
4. Scarcity/urgency
5. Curiosity gap

Include headline + body + CTA for each.
```

### 68. Social Media Calendar
**Plan content** that keeps you visible consistently.

**Social media calendar structure:**
- Format: Calendar grid (weeks × platforms)
- Content types: Mix of education, promotion, engagement
- Posting schedule: When to post for max reach
- Themes: What you're focusing on each week
- Cross-posting: Which posts work on multiple platforms
- Engagement plan: How you'll interact

**Example:**
```
Create a social media calendar for [platform/business].

Audience: [Who you're reaching]
Goal: [What you're trying to achieve]
Content pillars: [Main topics you discuss]
Posting frequency: [How often per week]
Best posting times: [When your audience is active]

Plan content for [4 weeks], including:
- Mix of content types (education/promo/personal/engagement)
- Specific posts (what you'll say, which platform)
- Cross-promotion strategy (repurpose content)
- Engagement tactics (how you'll respond)

Make it realistic to maintain.
```

### 69. YouTube Script Generator
**Structure video scripts** that engage and deliver value.

**YouTube script structure:**
1. Hook (first 5 seconds): Why should they watch?
2. Problem: What's the pain point?
3. Solution intro: "Here's what we're going to cover"
4. Main content: Deliver the value (with visuals in mind)
5. CTA mid-roll: Subscribe, like, comment
6. Deep dive: More detail if valuable
7. Takeaway: Remind them what they learned
8. Call-to-action: What should they do next?

**Example:**
```
Create a YouTube script for [video topic/idea].

Duration: [Video length]
Audience: [Who watches]
Goal: [Why you're making this video]
Main benefit: [What they'll learn]

Script should:
- Hook in first 5 seconds
- Answer their main question
- Include examples or demonstrations
- Feel conversational (like talking to a friend)
- Include natural CTA (subscribe, etc)
- End with clear next step

Format it so I can read it naturally.
```

### 70. Email Sequences
**Create series of emails** that nurture leads and drive action.

**Email sequence structure:**
- Email 1: Welcome (build relationship)
- Email 2: Deliver value (free content/resource)
- Email 3: Build credibility (case study, social proof)
- Email 4: Address objections (common hesitations)
- Email 5: Make the ask (soft sell)
- Email 6: Urgency (limited offer, deadline)
- Email 7: Last chance (final reminder)

**Example:**
```
Create an email sequence for [goal: sales, education, etc].

Audience: [Who you're emailing]
Goal: [What should happen after emails]
Trigger: [When does this sequence start]
Timeline: [How many days between emails]

Create 5 emails:
1. Welcome: Hook them, deliver immediate value
2. [Email 2]: Build relationship/credibility
3. [Email 3]: Address common objections
4. [Email 4]: Social proof (why others love this)
5. [Email 5]: Clear call-to-action

Each email should:
- Feel personal, not templated
- Have a single main point
- Include a call-to-action
- Be scannable

Write them in a conversational tone.
```

### 71. Product Descriptions
**Write compelling descriptions** that sell without being pushy.

**Product description structure:**
1. What it is (clear statement)
2. What it does (benefit to user)
3. Why it matters (why should they care)
4. Who it's for (specific use case)
5. Proof (testimonial, data, or feature)
6. Call-to-action (buy now, learn more)

**Example:**
```
Write a product description for [product].

Product: [Name, what it is]
Features: [What it does]
Benefits: [How it improves their life]
Target buyer: [Who would want this]
Price: [Cost, positioning]
Differentiator: [Why they should buy from you, not competitors]

Make it:
- Benefit-focused (not feature dumps)
- Specific and concrete (not vague)
- Scannable (short paragraphs, bullets)
- Confident (you believe in it)
- Action-oriented (tell them what to do next)

Include social proof if you have it.
```

### 72. Landing Page Copy
**Create compelling page** focused on converting one action.

**Landing page structure:**
1. Headline (clear benefit, keyword-rich)
2. Subheading (expands on benefit)
3. Hero image (visual of benefit)
4. Problem statement (why they're here)
5. Solution intro (what you offer)
6. Key benefits (3-5 main reasons)
7. Social proof (testimonials, numbers)
8. Close: Call-to-action button
9. FAQ (address doubts)

**Example:**
```
Create landing page copy for [offer/course/product].

Offer: [What you're promoting]
Target visitor: [Who's landing here]
Goal: [What action should they take]
Offer details: [Price, guarantee, what they get]
Competitive landscape: [Why you're different]
Objections: [Why they might not convert]

Create:
- Headline (clear, benefit-focused)
- Subheading (expands on headline)
- Problem section (why they should care)
- Solution section (what you offer)
- 3 key benefits (with examples)
- Social proof (testimonial or stat)
- FAQ (address top 3 objections)
- Clear CTA (tell them exactly what to do)

Make it conversion-focused, not salesy.
```

### 73. Content Repurposing System
**Turn one piece of content** into multiple formats.

**Repurposing strategy:**
- 1 blog post → Email, social posts, LinkedIn, video script, newsletter
- 1 video → Transcript, blog post, social clips, podcast episode
- 1 podcast → Transcript, blog post, social clips, YouTube
- 1 research finding → Blog post, infographic, social series, email

**Example:**
```
Create a content repurposing plan for [original content type].

Original content: [Description of what you have]
Audience segments: [Different people who'd find it valuable]
Platforms: [Where you have presence]

Show me how to turn this into:
1. Blog post (if it's a video/podcast)
2. Social media series (3-5 posts)
3. Email (1-2 emails)
4. Newsletter piece
5. [Any other format relevant]

For each version:
- Angle/hook (why this audience needs it)
- Format (what it looks like)
- Length/timing (how long/when to post)
- CTA (what do you want them to do)

Make it efficient so I can do this every time.
```

### 74. Hashtag Strategy
**Use hashtags strategically** to increase discovery.

**Hashtag categories:**
- Branded: Your hashtag (#YourBrand)
- Industry: General industry tags (#MarketingTips)
- Trending: What's popular now (#Viral trend)
- Niche: Specific audience tags (#SoloPreneursHelp)
- Community: Community tags (#WritersOfTwitter)

**Example:**
```
Create a hashtag strategy for [platform/business].

Brand: [Your business name/handle]
Industry: [Your niche]
Audience: [Who you're reaching]
Platform: [Where you're posting]

Develop:
1. 5 branded hashtags (your own, unique to you)
2. 10 industry hashtags (general, high volume)
3. 10 niche hashtags (specific, lower volume, more engaged)
4. Trending hashtags to monitor
5. Community hashtags relevant to your audience

Also:
- Which hashtags perform best (to track)
- How many to use per post (platform-specific)
- Hashtag rotation strategy (variety vs. consistency)
```

### 75. Content Strategy Framework
**Plan what content to create** and when.

**Content strategy elements:**
1. Goals: What you're trying to achieve (awareness, leads, sales)
2. Audience: Detailed profile (what they need, where they are)
3. Content pillars: Main topics (3-5 consistent themes)
4. Content mix: What types (blog, video, social, email, etc.)
5. Publishing schedule: When/how often
6. Distribution: Where you'll share
7. Metrics: How you'll measure success
8. Resources: What you need to execute

**Example:**
```
Create a content strategy for [business/personal brand].

Business: [What you do]
Goal: [What content should achieve]
Target audience: [Who you're reaching]
Timeline: [12 months]

Define:
1. 3-5 content pillars (main topics)
2. Content mix (% blog, video, social, email, etc.)
3. Publishing schedule (frequency, best times)
4. Platforms (where you're active)
5. Success metrics (what you'll measure)
6. Resource requirements (time, tools, help)

Then:
- Content calendar for first 12 weeks
- How to promote each piece
- How to measure what works
- How to iterate based on results

Make it realistic to maintain.
```

## Content Marketing Decision Tree

**Do you need organic traffic?**
→ **SEO blog outlines** + **Keyword research**

**Do you need to sell?**
→ **Landing page copy** + **Ad copy variations** + **Email sequences**

**Do you need to stay visible?**
→ **Social media calendar** + **Content repurposing**

**Do you need to build authority?**
→ **Blog posts** + **YouTube scripts** + **Case studies**

**Do you need a system?**
→ **Content strategy framework** + **Social media calendar** + **Editorial calendar**

