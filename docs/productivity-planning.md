# Productivity & Planning: Tricks 36-50

Build systems that actually stick.

## 15 Productivity & Planning Techniques

### 36. Build Weekly Plans & Checklists
**Create structure** that turns intentions into action.

**Weekly planning template:**
- Week overview: Key wins you need (3-5 max)
- Daily breakdown: What matters today
- Deep work blocks: When you focus
- Meetings/interactions: Batch them
- Review: What worked, what didn't

**Checklist structure:**
- Milestones (big things that matter)
- Tasks (concrete actions)
- Micro-tasks (if it takes 5 mins, put it here)
- Dependencies (what needs to happen first)

**Example:**
```
Build a weekly planning checklist for my role.
I need:
- A place to note my 3 key wins for the week
- A daily task list template
- A meeting log (so I can track where time goes)
- A Friday review section (what worked, what didn't)

Make it simple enough to use every week.
```

### 37. Draft SOPs & Templates
**Create reusable blueprints** for recurring work.

**SOP (Standard Operating Procedure) structure:**
1. Goal: What are we trying to accomplish?
2. Prerequisites: What needs to be true first?
3. Step-by-step: Exact sequence (numbered)
4. Quality check: How do you know it's done right?
5. Troubleshooting: What goes wrong and how to fix it

**Example:**
```
Create an SOP for [recurring process I do].

Currently I: [describe what you do]
Goal: [what should happen]
Time it should take: [realistic estimate]
Success looks like: [how you know it's done]

Make it detailed enough that someone else could follow it.
Include decision points where judgment is needed.
```

### 38. Automate Email Replies
**Set up smart systems** to reduce repetitive communication.

**What to automate:**
- FAQ responses (common questions → canned responses)
- Common asks (templates for typical requests)
- Meeting prep (automatic calendar follow-ups)
- Status updates (auto-send weekly summaries)

**Example:**
```
Create 5 email templates for common questions I get:
1. [Common question #1]
2. [Common question #2]
etc.

Each template should:
- Sound personal, not robotic
- Address the question fully
- Include any links/resources needed
- Have [brackets] where I personalize it

Make them sound like me—conversational, not corporate.
```

### 39. Build Meeting Agendas
**Structure meetings** so they actually accomplish something.

**Meeting agenda template:**
1. Goal: Why are we meeting? (1 sentence)
2. Duration: [Specific time limit]
3. Attendees: Who actually needs to be here?
4. Agenda items:
   - Item: [What we're discussing]
   - Owner: [Who leads this?]
   - Time: [X minutes]
5. Pre-read: [What should people read first?]
6. Decisions needed: [What will we decide?]
7. Next steps: [What's the follow-up?]

**Example:**
```
Create an agenda template for [meeting type].

We typically discuss: [list topics]
Usual attendees: [names/roles]
Ideal length: [duration]
Outcomes: [what should we decide/communicate]

Make it format I can copy-paste each week 
and just fill in this week's topics.
```

### 40. Set SMART Goals
**Create goals that are actually achievable and measurable.**

**SMART breakdown:**
- **S**pecific: Exactly what are you doing?
- **M**easurable: How will you know you succeeded?
- **A**chievable: Is it actually possible?
- **R**elevant: Does it matter to your larger goal?
- **T**ime-bound: When will you achieve this?

**Example:**
```
Help me turn these into SMART goals:

Vague goal: "Get better at public speaking"

Should become:
- Specific: Deliver presentations confidently
- Measured by: Delivering 3 talks (assessed by audience feedback)
- Achievable: Yes, I have time to prepare
- Relevant: Needed for my leadership goal
- Time-bound: By end of Q3

Create 3 SMART goals from these vague intentions: [list]
```

### 41. Time-Block a Full Day
**Map every hour** so nothing falls through the cracks.

**Time-blocking template:**
- 6-7am: Morning routine (exercise, breakfast, reading)
- 7-8am: Deep work (your best creative time)
- 8-9am: Email/messages
- 9-12pm: Meetings/collaborative work
- 12-1pm: Lunch + break
- 1-3pm: Deep work (second focused block)
- 3-4pm: Admin/catch-up
- 4-5pm: Meetings/interactions
- 5-6pm: Wrap-up, planning for tomorrow
- 6pm+: Personal time

**Example:**
```
Create a time-block for my typical day.

My priorities: [list in order]
My energy pattern: [when are you best? worst?]
Fixed commitments: [meetings, classes, etc.]
Ideal deep work blocks: [when can you focus?]

Allocate my time to respect this.
Include breaks. Include buffer time for unexpected stuff.
```

### 42. Delegation Frameworks
**Decide what to hand off** and to whom.

**Delegation decision tree:**
1. Does this need my specific skills? 
   - NO → Can someone else do it?
   - YES → Keep it or train someone
2. Is this the best use of my time?
   - NO → Find someone else
   - YES → Keep it
3. Will delegating it teach someone?
   - YES → Delegate with training
   - NO → Delegate with clear instructions

**Example:**
```
I'm drowning in [type of work].

Here's what I do: [list tasks]
What requires my expertise: [what only you can do]
What could others do: [what could be delegated]
Who could do it: [people available]

Create a delegation plan with:
- What gets delegated
- To whom
- How to hand it off (training vs. clear instructions)
- How to check in
```

### 43. Habit Tracker Builder
**Create systems** to track what matters most.

**Habit tracker structure:**
- Daily habits: Small, consistent actions
- Weekly habits: Things you do each week
- Milestones: Bigger achievements to track
- Metrics: Numbers that matter
- Review cycle: When you assess progress

**Example:**
```
Build a habit tracker for these goals:
1. [Goal with associated habits]
2. [Goal with associated habits]

For each goal, I want to track:
- Daily action: [what I'm doing every day]
- Weekly review: [what I'm checking on]
- Success metric: [how I know it's working]

Make it simple—something I'll actually use every day.
```

### 44. Project Planning Assistant
**Break projects into manageable phases** with clear milestones.

**Project plan structure:**
1. Goal: What's the end state?
2. Timeline: When should this be done?
3. Phases: Major chunks of work
   - Phase name: [what this phase accomplishes]
   - Tasks: [what needs to happen]
   - Owner: [who's responsible]
   - Timeline: [when it's done]
   - Blockers: [what could go wrong]
4. Dependencies: What needs to happen first?
5. Success criteria: How do we know it's done?

**Example:**
```
Help me plan [project].

Goal: [what we're trying to accomplish]
Timeline: [when should it be done]
Resources: [people, budget, tools available]
Constraints: [what we can't do, limitations]

Create a project plan with:
- 3-5 phases (clear sequence)
- Key milestones for each phase
- Who owns what
- Potential roadblocks and contingencies
```

### 45. Decision Trees & Brainstorms
**Map out complex decisions** visually and systematically.

**Decision tree structure:**
- Start at top with the decision
- Branch 1: If X is true, then...
- Branch 2: If Y is true, then...
- Keep branching until you reach outcomes
- Note: Which branch leads to best outcome?

**Example:**
```
I need to make a decision about [decision].

Context: [what's happening]
Options: [main paths I could take]
Important factors: [what actually matters]
Constraints: [what I can't do]

Create a decision tree that helps me think through this.
What's the likely outcome of each path?
```

### 46. Batch Task Grouping
**Group similar tasks** for flow and efficiency.

**Batching strategy:**
- Group 1: All communication (email, Slack, calls)
- Group 2: All creative work (writing, design, strategy)
- Group 3: All admin (billing, scheduling, forms)
- Group 4: All meetings
- Group 5: All review/feedback

**Example:**
```
I do these types of work throughout the day: [list]

Create a batching schedule where I:
- Do all [type] work in one time block
- Do all [type] work in another block
- etc.

This should reduce context switching and help me get in flow.
```

### 47. Build Personal Dashboards
**Create visual overview** of what matters most.

**Dashboard elements:**
- Key metrics: Numbers that show health
- Current projects: Where things stand
- Upcoming deadlines: What's due when
- Priorities: This week's focus
- Recent wins: What's working

**Example:**
```
Create a personal dashboard template I can update weekly.

I track:
- Metric 1: [key number]
- Metric 2: [key number]
- Metric 3: [key number]
Current projects: [what I'm working on]
This week's focus: [top 3]
Upcoming blockers: [what might slow us down]

Make it one-page, visual, something I review every Monday.
```

### 48. Action Items & Accountability
**Make decisions actionable** with clear ownership and deadlines.

**Action item template:**
- Action: [Specific, concrete task]
- Owner: [Who's doing this?]
- Deadline: [When's it due?]
- Success criteria: [How do you know it's done?]
- Blocker: [What could get in the way?]

**Example:**
```
After this meeting/decision, create a list of action items.

Include:
- What exactly needs to happen
- Who owns it (name + role)
- When it's due (specific date)
- How we know it's complete
- Any dependencies or risks

Then: Who's tracking this? How often do we check in?
```

### 49. Prioritization by Impact
**Rank work** by what actually matters, not what feels urgent.

**Impact ranking process:**
1. List all tasks/projects
2. For each: Rate impact (1-10) if completed
3. For each: Rate effort (1-10) to complete
4. High impact + low effort = DO FIRST
5. High impact + high effort = PLAN IT
6. Low impact + low effort = BATCH IT
7. Low impact + high effort = SKIP IT

**Example:**
```
I have too much to do: [list everything]

Help me prioritize by:
1. Impact: Which would move the needle most?
2. Effort: Which take most time/energy?
3. Deadline: Which are time-sensitive?

Create a prioritized list showing:
- What I should do this week
- What I should schedule for next month
- What I should delegate
- What I should skip
```

### 50. Workflow Diagrams
**Map processes visually** so they're clear and repeatable.

**Workflow elements:**
- Start point: Where does this begin?
- Decision points: Where do things branch?
- Steps: Linear progression
- Outcomes: Where does it end?
- Feedback loops: Any iterative parts?

**Example:**
```
Create a workflow diagram for [process].

Current process: [describe how it works now]
Problems: [what's inefficient or confusing]
Goal: [what should the process do]

Show me:
- All the steps
- Where decisions happen (who decides)
- Where things can go wrong
- How information flows
- Where we should automate

Use a format I can share with my team.
```

## Real-World Example

**Weak productivity setup:**
```
Help me get more organized.
```

**Strong productivity setup:**
```
I'm overwhelmed and nothing gets done consistently.

Here's what I need to manage:
- Work: [types of work]
- Personal: [commitments]
- Goals: [what I'm trying to achieve]

My challenges:
- Too many priorities at once
- Forget about things
- Context-switching all day
- Never know if I'm making progress

Create a productivity system that includes:
1. A weekly planning template
2. A time-blocking schedule (show how to structure my day)
3. A priority matrix (what to do first)
4. A habit tracker (these are the habits that matter)
5. A weekly review checklist

Make it simple—I'll abandon complex systems.
```

**The difference:** Specific context + defined goals + multiple systems that work together = sustainable productivity.
